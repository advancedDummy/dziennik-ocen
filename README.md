# Dziennik ocen

Projekt na przedmiot **Metody Wirtualizacji**.

## Opis
Aplikacja do prowadzenia dziennika ocen z wykorzystaniem wirtualizacji i konteneryzacji (Docker).

## Skład grupy
- Franciszek Wybicki
- Miłosz Wybrański

## Stack technologiczny
- Frontend (kontener)
- Backend (kontener)
- Baza danych (oficjalny obraz w kontenerze)
- Docker / Docker Compose
- Komunikacja HTTP + JSON

## Status
Projekt w fazie początkowej (Zajęcia 1).
Projekt rozwiniety o szkielet aplikacji - 3 kontenery i prosty test komunikacji.
